# 蒜串屋 網站：上線與 SEO 操作手冊

網站檔案都在 `site/` 資料夾裡。
**所有內容（店名、地址、電話、菜單、價格、文案）都在 `site/build.py` 裡修改**，改完執行：

```
python build.py
```

這樣中文、英文、日文三個頁面會一起更新。

---

## 第 1 步：開店前一定要換掉的資料

打開 `site/build.py`，搜尋 `TODO`，逐項換成真實資料：

| 項目 | 說明 |
|---|---|
| `domain` | 你買的網域，例如 `https://www.你的店名.tw` |
| `name` | 店名（目前「蒜串屋」是暫定名） |
| `phone` / `phone_display` | 店家電話 |
| `address` / `street_schema` | 地址（中、英、日三種寫法） |
| `geo` | 店的經緯度：在 Google Maps 上對店面按右鍵，第一行就是 |
| `maps_query` | Google 商家檔案建好後，改成「店名＋地址」 |
| `reserve_url` | 線上候位／訂位連結（LINE 官方帳號、inline、EZTABLE 都可以） |
| `review_url` | Google 評論連結（見第 3 步） |
| `instagram` / `facebook` / `ubereats` / `foodpanda` | 你的帳號連結 |
| `MENU` / `DRINK_PLANS` | 品項與價格（目前是依市調訂的建議價） |
| 營業時間 | `build.py` 的 `HOURS_SCHEMA`、各語言的 `hours_rows`，**還有** `assets/app.js` 最上面的 `HOURS` |
| `PHOTOS` | 目前是 Unsplash 的示意照片，**開店後一定要換成自家照片**（自家實拍對轉換率和 Google 排名都有幫助） |

另外，文案裡有幾句是「店家的承諾」，請確認你真的做得到，做不到就改掉：
- 「不收服務費、沒有低消」
- 「有冷氣」「線上候位」
- 「捷運忠孝敦化站 3 號出口走路 3 分鐘」（要依實際地點改）
- 「平日 20 人以上可包場」

## 第 2 步：把網站放上網（免費）

推薦用 **Cloudflare Pages** 或 **Netlify**，兩個都免費，速度也快：

1. 註冊 Netlify（https://app.netlify.com）
2. 選「Add new site → Deploy manually」
3. 把整個 `site` 資料夾拖進去，就上線了
4. 在「Domain settings」綁定你買的網域（網域可以在 Gandi、Namecheap、PChome 買，`.tw` 一年約 NT$800，`.com` 約 NT$400）
5. 之後改了內容就重新跑 `python build.py`，再把資料夾拖上去一次

## 第 3 步：Google 商家檔案（本地 SEO 最重要的一步）

在 Google Maps 上搜「串燒」，排在前面的店，靠的主要是 Google 商家檔案，不是網站本身。

1. 到 https://business.google.com 建立商家
2. **店名、地址、電話要和網站上一字不差**（Google 會交叉比對，一致才會加分）
3. 主要類別選「居酒屋」或「串燒餐廳」，次要類別加「炸雞餐廳」「宵夜」相關類別
4. 網站欄位填你的網域；菜單連結填 `https://你的網域/#menu`；預訂連結填你的候位連結
5. 上傳至少 10 張實拍照片：門面（讓人找得到）、招牌菜特寫、店內座位、烤台
6. 營業時間設定正確，國定假日要另外設
7. 驗證完成後，到商家檔案的「取得更多評論」複製評論連結，填進 `build.py` 的 `review_url`
8. 每週發一則「最新動態」（新品、季節限定），Google 會把活躍的商家排前面

### 評論：可以做的與不能做的

- ✅ 可以：桌上放 QR Code、結帳時口頭邀請、網站上放「寫評論」按鈕（網站已經有了）
- ✅ 可以：每則評論都回覆，負評也要誠懇回覆
- ❌ 不可以：「給五星送生蠔／送一串」這類用好處換評論的做法。這違反 Google 政策，被檢舉後評論可能被大量刪除，甚至被暫停商家檔案。

---

## 第 4 步：Google Search Console

1. 到 https://search.google.com/search-console 新增你的網域
2. 驗證完成後，在「Sitemap」提交 `https://你的網域/sitemap.xml`
3. 用「網址審查」檢查首頁，按「要求建立索引」
4. 到 https://search.google.com/test/rich-results 貼上網址，確認「Restaurant」和「FAQ」結構化資料沒有錯誤

## 這個網站已經做好的 SEO 項目

- 每個語言的頁面都有獨立網址（`/`、`/en/`、`/ja/`），並用 hreflang 互相標記，觀光客用英文、日文搜尋也找得到
- 標題和描述都放了目標關鍵字：區域（忠孝敦化、東區）＋品類（串燒、炸物、居酒屋）＋需求（宵夜、營業到 01:30）
- Restaurant 結構化資料：地址、經緯度、電話、營業時間、價位、完整菜單和價格
- FAQPage 結構化資料：有機會在搜尋結果直接顯示問答
- 菜單是可以被搜尋的文字，不是圖片
- 已嵌入 Google 地圖；一鍵導航、一鍵撥號；手機版底部固定「導航／電話／候位」三顆按鈕
- 頁面會依台北時間即時顯示「營業中／準備中」
- 照片使用響應式尺寸、延遲載入，手機版開得快
- `sitemap.xml`、`robots.txt` 都已產生

## 之後可以加強的方向

- **部落格／文章頁**：例如「忠孝敦化宵夜推薦」「鹹酥雞和串燒怎麼配酒」，可以吃到長尾關鍵字
- **找部落客和 IG 美食帳號試吃**：外部連結和曝光是 Google 排名的重要因素
- **在愛食記、Tripadvisor、Google 都建立一致的店家資料**
- **自家照片**：換掉示意照片後，記得在每張照片的 `alt` 寫清楚菜名
